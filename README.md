# Construction Company Backend API

A production-ready Node.js/Express/MongoDB backend for a Construction Company website. This API handles project portfolio management, contact form inquiries, and secure admin authentication.

## Features

- **Project Management**: CRUD operations for construction projects.
- **Contact System**: Submission and management of user inquiries (leads).
- **Security**: 
    - JWT-based Authentication
    - Password hashing using BCrypt
    - CORS protection
    - Request validation using Express Validator
- **Deployment**: Includes Dockerfile for easy containerization.
- **Data Seeding**: One-command setup for initial admin and sample data.

## Prerequisites

- **Node.js**: v16.x or higher
- **MongoDB**: Local installation or MongoDB Atlas URI
- **NPM** or **Yarn**
